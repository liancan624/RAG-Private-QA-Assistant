# 基于混合检索的私有化知识库问答系统
> 面向垂直领域的可本地部署 RAG 问答系统，支持自定义大模型、私有知识库管理、混合语义检索，数据完全本地可控。

## 项目简介
本项目是一套可私有化部署的知识库问答系统，基于 LangChain 生态构建完整 RAG 流水线，实现多格式文档解析、语义分块、混合检索、语义重排的全链路能力。系统采用前后端分离的分层工程架构，支持多知识库物理隔离，可快速接入任意兼容 OpenAI 协议的大模型，为垂直领域提供精准、可溯源的智能问答服务。

## 核心特性
- **三级混合检索机制**：采用「BM25 关键词精确匹配 + 向量语义泛化召回 + BGE 中文重排精筛」的三级检索架构，兼顾专业术语准确率与语义理解能力，垂直场景检索准确率显著提升
- **多知识库物理隔离**：支持创建多个独立知识库，数据物理存储隔离，可快速切换领域，适配多业务场景
- **自定义大模型兼容**：兼容所有遵循 OpenAI 接口协议的大模型，可灵活配置模型名称、接口地址、API 密钥
- **多格式文档支持**：支持 PDF、DOCX、TXT、Markdown 等主流文档格式，自动解析与语义分块
- **语义分块优化**：基于语义相似度的智能分块，配合中文分词优化，避免语义截断，保障块内语义完整性
- **回答可溯源**：所有回答附带原文引用来源，支持定位到对应文档，结果可验证、可追溯
- **私有化本地部署**：文档与向量数据全部本地存储，数据自主可控，支持离线环境部署

## 技术架构
系统采用分层解耦的工程化架构，各层职责单一，便于扩展与维护：

1. **接口层（API）**：基于 FastAPI 封装 RESTful 接口，负责请求接入、参数校验、结果统一返回
2. **服务层（Service）**：封装业务流程，衔接接口层与数据层，编排知识库构建、检索等核心业务
3. **核心层（Core）**：RAG 核心能力实现，包含问答编排、混合检索器、语义重排组件
4. **工具层（Utils）**：通用工具能力，包含文档解析、中文分词、语义分块等无状态工具
5. **数据层（DB）**：数据持久化交互，包含 Chroma 向量数据库、BM25 倒排索引的封装
6. **前端层（Frontend）**：基于 Streamlit 实现的可视化交互界面，快速验证产品能力

### 检索流水线
```
用户问题 → 中文分词预处理 → 双路并行召回
├─ BM25 关键词检索 → 精确匹配专业术语、专有名词
└─ 向量语义检索 → 泛化匹配同义表达、语义相关内容
    ↓
两路结果归一化加权融合 → 去重取 Top N
    ↓
BGE 中文重排模型 → 二级语义精筛
    ↓
召回结果送入大模型生成回答 → 附带引用来源返回
```

## 快速开始

### 环境准备
1. 创建并激活 Python 虚拟环境
2. 安装项目依赖
```bash
pip install -r requirements.txt
```

### 启动后端服务
在项目根目录执行：
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
- 服务启动后自动加载嵌入模型与重排模型
- 接口文档地址：[http://localhost:8000/docs](http://localhost:8000/docs)

### 启动前端界面
在项目根目录执行：
```bash
streamlit run frontend/streamlit_app.py
```
- 启动后浏览器自动打开交互界面
- 默认对接后端地址：[http://localhost:8000](http://localhost:8000)

## 功能说明

### 1.模型配置
- 支持自定义配置大模型名称、API 密钥、接口地址
- 提供连通性测试功能，一键验证模型配置是否可用
  
### 2.知识库管理
- 支持创建多个独立知识库，实现不同领域数据物理隔离
- 支持上传多格式文档，批量上传自动解析存储
- 一键构建知识库索引，同步生成向量库与 BM25 倒排索引
- 知识库列表展示，包含文件数量、构建状态
  
### 3.智能问答
- 基于当前知识库进行问答，自动调用混合检索机制
- 回答结果附带原文引用来源，支持展开查看对应片段
- 支持开启 / 关闭语义重排，可调节召回数量
